## 验证边界

编辑范围来自保守的 Intel FSP 编辑器约束，不是全部运行时合法值或每个 SKU 的可写保证。
本轮没有真实 B7 调节、其它物理表项副作用或稳定性验收；配置回读不证明 TVB 正在生效。
逐物理核心表、全表设置、一键 Boost、Vmax stress、Ring DownBin、其它型号仍待恢复。
AMD P-state 写入、完整 MP1/PBO 和板级调节等缺口以及真机 / Secure Boot 验收仍存在。
Windows/macOS 的结果只表示独立核心通过，不表示完整硬件或 GUI 移植。
