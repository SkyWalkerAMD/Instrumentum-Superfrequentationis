# UMC 离线导入与比较：GUI / CLI 同步验证

生产提交 `672422ae21b7b3f9a1b9a1455158a461239eee61`，研究分支 `refactor/platform-recovery`。
[证据清单](validation/umc-offline-ci-672422a.json)固定工作流、日志、安装包、源码及校验值。
[使用说明](umc-offline.md)记录格式、文件上限、比较语义与命令示例。

GUI、CLI 共用有资源上限的 UTF-8 JSON 解析与 212 字段比较实现，补齐 GUI 快照回传 CLI 的流程。
支持成功的 CLI 采集/解码报告，拒绝不完整的成功采集；部分 GUI 快照仍显示缺失状态。
比较区分字段变化、寄存器其它位变化、单边/双边缺失，要求同 bank/slot，不假设物理通道相同。
新增路径不创建硬件后端，不执行设置命令。

## 验证边界

这批交付完成离线处理和比较，未新增内存时序写入、物理单位换算或自动通道识别。
核心跨平台测试不代表 Windows/macOS 的硬件后端已完成。AMD PStates 写入、曲线/完整 PBO
设置、Intel 其它型号和板级控制仍有协议缺口，详见[还原状态](recovery-status.md)。
四台目标真机、调参稳定性、Secure Boot 实机部署与跨版本升级仍未验收。
