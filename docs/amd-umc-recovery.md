# AMD UMC 字段与通道选择恢复

这次恢复原版的 212 个 UMC 字段、12 个展示分组，以及明确选择寄存器组的读取和快照文件。
它补充运行控制器寄存器读取，不把 SPD 基础时序当作当前训练结果。
完整 DDR4/DDR5 型号解释、Intel 内存时序、训练写入、PMIC/VRM/EC 控制仍未恢复。

## 原始代码证据

固定 ELF SHA-256 `44598dc8177050599afcc46f6355504161f942330d7917d1aaa010d864aaff10`。
[字段契约](../analysis/contracts/amd-umc-fields.json)来自完整原构造常量前缀；
[字段执行结果](validation/legacy-amd-umc-analysis.json)用五组模拟输入执行完整
`AMD_UMC::Populate_Values`，每组核对 212 个字段和 12 组结果。
其 PCI 读取使用 E0 索引/E4 数据，间隔 4 ms，56 个唯一偏移。
底层 `RW_MMIO_AMD` 构造、PCI/ libc 边界均为替身，没有访问真实硬件。

原分组按名称取首个匹配项，遮蔽后面的 Cmd2t、Tcl、Tcwl、Tmod、Tmrd、Txs。
重构版按唯一 ID 与偏移定位，并按同名出现顺序绑定分组；两个 Tcl 可以各自显示 34 与 63。
这恢复全部字段，不擅自断言后一处属于 DDR5、某个 DIMM 或当前生效模式。
值保留原编码；原 GUI 的 Cmd2t 加一显示也没有被当作普遍的周期换算规则。
描述符和原指令测试向量由[生成器](../analysis/tools/generate-amd-umc-tables.py)生成，可用 `--check` 验证。

## 通道搜索问题

[完整构造实验](validation/legacy-amd-umc-selection.json)执行 19 组合成输入，覆盖六个 PCI ID、
Shimada/Granite/TR5 标志、BDF 回退、地址空洞、频率缺失和刷新槽搜索。
模拟输入与独立的期望地址序列均保存在结果中；不作为真机验证。

- 初始四次读取全为 `0xffffffff` 时，原程序把初始偏移推进到没有探测过的第五处后继续。
- 所有候选频率无效时，原程序仍保留最后地址，没有“未发现有效通道”的返回。
- Shimada/TR5 的特定循环在读取有效频率后，先推进地址再判断是否结束。
  合成输入重现频率来自 `0x150200`，后续刷新读取却使用 `0x250260`。
- `0x260` 低 12 位为 `0x138` 时，原程序搜索四组、每组四字，使用第一个非空组的最后一个
  非哨兵偏移。全部为哨兵时保留初始偏移 0；没有证明该槽对应哪根 DIMM。
- 最长 Shimada 路径可触及地址组 22。这个上限用于输入编码边界，不证明存在 23 个通道。

重构版不复制这些自动选择规则。用户明确选择地址组和刷新槽；没有有效频率字段、身份不符或
任一步读取失败时，不发布时序表。不扫描 PCI，不将逻辑 CPU、地址组和 DIMM 标签混为一谈。

## 实现边界与使用

新增 AMD UMC 页，点击 Read once 才访问硬件。CPUID 必须为 AMD Family 1Ah，所选 BDF 的 ID
必须为 `1022:153a` 或 `1022:14d8`，对应原 Shimada/Granite 入口。这个匹配不认证主板或固件。
地址组 `n` 使用 `0x50000 + n*0x100000`；刷新槽 `s` 对 0x260/0x2c0 使用
`(s/4)*0x100 + (s%4)*4` 偏移。两项均显式展示，不凭产品名称选择默认通道。

一轮读取在同一个 HardwareService 事务内串行；只写 E0 索引，从不写 E4 数据。
进程内互斥不排除其它进程或驱动同时访问。失败立即停止，不重试，不把不完整快照显示成时序。
关闭窗口会取消后续请求，但不能中断已经进入操作系统的请求。

快照采用 `octool-amd-umc-v1` JSON，包含原始寄存器、地址组、刷新槽及采集身份。
离线导入不访问硬件，不相信文件中的平台身份；最多 64 KiB / 56 项，拒绝重复偏移、非法数字和
未知偏移。允许部分捕获，缺失字段显示为空。保存使用临时文件提交，避免覆盖为半份快照。

两个 PCI 入口、113 个传输失败位置和取消。Qt 测试检查零启动访问、离线双 Tcl 显示、快照回读、
恶意或损坏输入清空、错误 CPU/PCI 输入不访问控制器。

十目标各 24 Qt / 30 Python、11 套内核 VM、20 份安装包。完整数据及哈希见
[本次验证](validation/umc-recovery-ci-728671d.json)。这是合成回归与软件兼容性结果，不代替真机字段验收。
